# EvE All in One — demo

**Try it:** https://gwenrb.github.io/EvE-All-in-one-Demo/

A look at EvE All in One, a tool for running EVE Online industry across several characters: skills, jobs, assets, prices, build planning, reactions, PI, orders, hauling, forecasts and more.

- **The pilots, hangars, wallets, jobs and fittings are mock data**, the same for every visitor. Market prices, the map, sovereignty and kills are live.
- **Nothing is sent anywhere:** everything you change stays in your browser. *Reset the demo* on the bar at the top puts it back.
- **Logins are off.** The demo can't link your own characters, and it has no backup import or export.
- The first visit downloads CCP's game data once (about 100 MB, straight from CCP), so allow a minute or two.

This repository only holds the built demo page. The tool itself isn't published here.
